# 📒 دفتر الديون — تطبيق ويب لإدارة ديون العملاء

تطبيق ويب متكامل (HTML / CSS / JavaScript) لإدارة ديون العملاء وسداداتهم،
يعمل بالكامل من المتصفح بدون أي خادم أو اتصال إنترنت، ويخزّن جميع البيانات
محلياً على جهازك (localStorage). يتميّز بخاصية **تسجيل صوتي ذكي** تحوّل
كلامك مباشرة إلى معاملة دين أو سداد جاهزة للحفظ.

## 🚀 طريقة التشغيل

لا يحتاج المشروع لأي تثبيت أو إعداد:

1. فك ضغط الملف.
2. افتح ملف **`index.html`** مباشرة في متصفح **Google Chrome** (يُفضّل)
   لأن خاصية التسجيل الصوتي تعتمد على Web Speech API المتوفرة بشكل كامل في Chrome.
3. عند أول استخدام لميزة التسجيل الصوتي سيطلب المتصفح إذن استخدام الميكروفون — اسمح به.
4. جميع بياناتك تُحفظ تلقائياً في متصفحك، ولن تُفقد عند إغلاق الصفحة (إلا إذا مسحت بيانات المتصفح).

> **ملاحظة عن الصوت:** التعرف على الكلام (Speech-to-Text) يعمل عبر ميزة
> متصفح مدمجة (Web Speech API) وهي **مجانية ولا تحتاج مفتاح API**، لكنها
> تحتاج اتصال إنترنت لحظة التسجيل فقط (المعالجة تتم من طرف جوجل داخل المتصفح).
> إن لم يدعم متصفحك هذه الميزة، سيظهر مربع "إدخال يدوي" لكتابة الجملة والحصول
> على نفس نتيجة التحليل الذكي.

## 🎯 المميزات

### 📱 إدارة العملاء
- إضافة/تعديل/حذف بيانات العملاء (الاسم، الهاتف، العنوان، ملاحظات)
- بحث وتصفية فورية (مدينون / دائنون / مسدَّدون)
- صفحة تفاصيل لكل عميل مع كشف حساب كامل

### 💰 إدارة الديون والسداد
- تسجيل الديون والسداد بضغطة واحدة
- كشف حساب تفصيلي يعرض الرصيد بعد كل معاملة
- حساب الرصيد الحالي لكل عميل تلقائياً

### 🎤 التسجيل الصوتي الذكي
- تحويل الكلام العربي إلى نص مباشرة من المتصفح
- محرك تحليل قواعدي مخصص للعربية يستخرج تلقائياً:
  اسم العميل، المبلغ (أرقام أو كلمات مثل "خمسمية")، نوع المعاملة (دين/سداد)، والملاحظة
- عرض **درجة ثقة** التحليل (٪) حسب وضوح الجملة
- شاشة **مراجعة وتصحيح** كل حقل يدوياً قبل الحفظ النهائي — لا يُحفظ شيء تلقائياً بدون تأكيدك

### 📊 التقارير والإحصائيات
- إجمالي الديون، إجمالي السداد، نسبة التحصيل
- رسم بياني لحركة آخر 6 أشهر (ديون مقابل سداد)
- رسم دائري لتوزيع حالة العملاء
- قائمة أكثر 10 عملاء مديونية
- إرسال تقرير حساب العميل مباشرة عبر واتساب (رابط wa.me)

### 📤 التصدير والمشاركة
- تصدير قائمة العملاء أو المعاملات أو كل البيانات إلى **Excel (CSV)**
  متوافق مع النصوص العربية (UTF-8 مع BOM)
- تصدير كشف حساب أي عميل كـ **فاتورة PDF** (عبر طباعة المتصفح "حفظ كـ PDF")

### ⚙️ الإعدادات
- التبديل بين الوضع الفاتح والداكن
- اختيار رمز العملة المعروض
- اسم ورقم واتساب النشاط التجاري (يظهران في الفواتير)
- نافذة "عن المطوّر"

## 🔒 الخصوصية والبيانات

جميع البيانات (العملاء، المعاملات، الإعدادات) تُخزَّن **محلياً فقط** داخل
متصفحك (`localStorage`) على جهازك، ولا يتم إرسالها إلى أي خادم خارجي.
احرص على تصدير نسخة Excel احتياطية بشكل دوري من شاشة "الإعدادات".
